# Site — Luana Bandouk Atelier

Site institucional + catálogo de vestidos, em HTML, CSS e JavaScript puros (**sem build, sem Node.js**).
Hospeda de graça no Cloudflare Pages (build vazio, saída `/`) ou GitHub Pages.

```
index.html            estrutura da página
css/style.css         cores, fontes e layout (variáveis no topo)
js/content.js         >>> TEXTOS, TELEFONE/WHATSAPP, MENSAGENS, GALERIA, DEPOIMENTOS, FAQ <<<
js/catalogo.js        >>> LISTA DE VESTIDOS (1 linha por vestido) <<<
js/main.js            lógica (normalmente não se mexe)
assets/img/           marca, catalogo, galeria
GUIA-DE-EDICAO.md     passo a passo para alterar tudo
GUIA-DE-PUBLICACAO.md GitHub + Cloudflare Pages + domínio
```

Ver no computador: dois cliques em `index.html` (mapa e fontes precisam de internet).
